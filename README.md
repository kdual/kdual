# 한국공학대학교 공동훈련센터 VOC

한국공학대학교 일학습병행 공동훈련센터용 GitHub Pages VOC 관리 웹페이지입니다.

## 디자인
- 한국공학대학교 브랜드 컬러 적용
  - #1758A8
  - #068FD3
  - #01B3CD
- 티노(TINO) 마스코트 적용
- 공공기관형 정보구조 + 모바일 반응형 UI

## 실행
1. 저장소 루트에 전체 파일을 업로드합니다.
2. GitHub 저장소 `Settings > Pages`로 이동합니다.
3. `Deploy from a branch > main > /(root)`를 선택합니다.

## 데이터 수정
`data/voc.json`만 수정하면 검색·필터·통계에 자동 반영됩니다.

## 파일 구조
- index.html
- css/style.css
- js/app.js
- data/voc.json
- images/tino.png
