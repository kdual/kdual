# FAQ 관리 방법

홈페이지 메뉴 순서는 **전체 / 간담회 / 커뮤니티 / 제도개선 / FAQ**로 고정됩니다.

현재 관리용 Google Sheets의 `FAQ` 탭에서 다음 항목을 입력합니다.

| 위치 | 항목 | 입력 방법 |
| --- | --- | --- |
| I열 | 대주제 | 간담회, 커뮤니티, 제도개선, FAQ 중 선택 |
| J열 | 하위 주제 | 간담회·커뮤니티·제도개선의 하위 이름을 자유롭게 입력. 예: 2025년 상반기, 2026년 하반기 |
| C열·D열 | 질문·답변 | 기존과 동일 |
| E열 | 공개여부 | 공개된 글만 홈페이지와 하위 메뉴에 표시 |

- 같은 대주제에 같은 하위 주제를 입력한 글은 같은 메뉴로 묶입니다.
- 새로운 하위 이름을 입력하면 해당 공개 글이 동기화될 때 메뉴가 자동 추가됩니다.
- 하위 주제를 바꾸려면 해당 글들의 J열을 함께 수정합니다.
- 하위 주제가 비어 있는 글은 해당 대주제의 **전체**에서 볼 수 있습니다.
- FAQ 대주제는 하위 메뉴를 사용하지 않습니다.
- 하위 메뉴 순서는 중요 글 우선으로 정렬한 게시글에서 이름이 처음 나타난 순서입니다.
- 동기화는 기존 5분 예약 작업으로 진행됩니다. GitHub 예약 실행이 지연되면 반영도 늦어질 수 있습니다.
- B열 `분류`는 I열과 J열을 합치는 자동 연동 수식이며 직접 수정하지 않습니다. 기존 Apps Script의 A:H 필드 위치와 헤더를 유지합니다.
- 입력 준비는 1,000행까지 되어 있습니다. 그 이후로 확장할 때는 I/J 입력 서식과 B열 수식도 함께 확장합니다.

## 새 담당자 계정 연결

GitHub 코드를 새 담당자 저장소에 복사하고, Google Sheets도 새 담당자 계정에 복사합니다. B열 수식과 I/J 입력 항목을 포함한 전체 시트 구조를 복사해야 합니다. 기존과 동일한 A:H 데이터를 반환하는 Apps Script를 새 계정에서 생성·배포한 뒤 홈페이지의 `FAQ_CONFIG.apiUrl`, 관리 시트 링크와 `.github/workflows/sync-faq.yml`의 `FAQ_API_URL`을 새 주소로 바꿉니다.

API의 `category`는 `간담회 / 2026년 하반기`처럼 전달할 수 있습니다. 홈페이지는 이 값을 대주제와 하위 주제로 분리합니다. `topic` 또는 `subtopic` 필드를 별도로 반환하는 API도 지원합니다. 기존 단일 분류는 그대로 지원하며 기존 기타 분류의 글은 FAQ에 표시합니다.
